Learn how to use CloudConnect

1 Getting started with CloudConnect

This CloudConnect Designer project demonstrates how to upload data from a CSV file to a GoodData project.

This project is a simple transactional system for tracking stock quotes. It illustrates the following concepts of CloudConnect Designer:

  • Logical Data Model,
  • ETL,
  • Metadata and components,
  • Test, execute, and publish.

2 Reading from Twitter

This CloudConnect Designer project demonstrates how to extract data from Twitter, perform some transformations to the data, and upload the data to a GoodData project.

This project gathers tweets that contain a reference to gooddata. It illustrates the following concepts of CloudConnect Designer:

  • Reading data from an URL,
  • Parsing JSON,
  • Reformat data,
  • Debugging ETL,
  • Logical Data Model,
  • Test, execute, and publish.

Try this demo

3 Reading from SalesForce

This CloudConnect Designer project demonstrates how to extract data from Salesforce, merge multiple datastreams, and upload the data to a GoodData project.

This project tracks opportunities in Salesforce. It illustrates the following advanced concepts of CloudConnect Designer:

  • Reading from external service,
  • LDM with multiple datasets,
  • ETL merging from multiple sources,
  • Metadata and components,
  • Test, execute, and publish.

5 Many to many relation

This CloudConnect Designer project demonstrates how to create a model using many-to-many relationships and how to upload CSV data to this model. Sample CSV files are included.

This project models ticket and tagging information for a simple service management application. It illustrates the following concepts of CloudConnect Designer:

  • M:N data model,
  • Metadata and components,
  • Debugging ETL,
  • Test, execute, and publish.
